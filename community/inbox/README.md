# The inbox

One contribution per file, named `YYYY-MM-DD-<your-name>-<slug>.md`, shaped
like `community/TEMPLATE.md`, with your stamp on line two. The rules and
the why: `community/README.md`. The gate that reads every pull request:
`reference tools/contribution_lint.py`.

This README is the maintainer's; a pull request that edits it is refused
by the lint, as is any file here that is not markdown.
